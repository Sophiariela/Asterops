## Diagnostic (new)

| File | Shows |
| --- | --- |
| `01-diagnostic.png` | Question 1 — progress bar, radio options, disabled Back |
| `02-diagnostic.png` | A mid-flow question with an option selected (accent/9 fill, accent/45 border) |
| `03-diagnostic.png` | Result — CommerceOS + OperationsOS, "Start here" pill, fit bars, Aster Pro tier card |

The result frame is a real run of the scoring rules, fed these answers: physical products ·
2–5 years · people find us but don't buy · old site nobody updates · through DMs · spreadsheets ·
follow-up and admin · improving what we have · several tools plus data to migrate.
That produces CommerceOS primary, OperationsOS second, and **Aster Pro** (because
`migration > 0`). Useful as a test case when you port the engine.
